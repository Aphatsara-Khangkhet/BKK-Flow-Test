# Data dictionary และข้อตกลง

| คอลัมน์ | ความหมาย/กติกา |
|---|---|
|id|รหัสเดิมจากชีต ไม่ใช้แทนหน่วยการสังเกต|
|source_excel_row|เลขแถวจริงใน traffic_data รวม header แล้ว ใช้ย้อนตรวจต้นฉบับ|
|source_sha256|fingerprint ของ workbook snapshot ที่ตรวจ|
|covid_period|กลุ่มจากไฟล์โดยตรง: ก่อนโควิด / โควิด / หลังโควิด|
|Date, month, year|วัน เดือน ปีของรายงาน เก็บเดิมทั้งหมด|
|report_day, report_month, report_year|ค่าตัวเลขที่แปลงจาก Date/month/year|
|report_date|วันที่รายงานที่ประกอบได้ หากวันไม่มี/เป็นวันที่เป็นไปไม่ได้ให้ว่างและติดรายการตรวจ ไม่ถือว่าทั้งแถวใช้ไม่ได้|
|survey_date|วันที่สำรวจต้นทาง ไม่ต้องตรงกับ report_date|
|survey_date_parsed|datetime ที่แปลงข้อความไทย/Excel datetime; ไม่กำหนด COVID period จากค่านี้|
|intersection, road|ชื่อเดิม|
|intersection_key, road_key|ปรับ NFC Unicode กับ trim/ยุบ whitespace เท่านั้น ไม่ยืนยันการสะกดหรือเอกลักษณ์ทางภูมิศาสตร์|
|time_period|ชื่อ/เวลาต้นทาง|
|start_time, end_time, period_hours|เวลาและชั่วโมงจากข้อความจริง เช่น 07:00–09:00 = 2 ชั่วโมง|
|passenger_car, pickup_van, large_bus, small_bus, truck, tuk_tuk|จำนวนรถเดิมทั้ง 6 ประเภท|
|ชื่อประเภทรถ_clean|ค่าตัวเลขสำหรับทำงาน แทนเฉพาะช่องว่างและ - ด้วย 0 และลบ comma คั่นหลักพัน|
|ชื่อประเภทรถ_zero_assumed|บันทึกว่าค่านี้กลายเป็น 0 ตามสมมติฐานผู้ใช้|
|Unnamed: 16, Unnamed: 17|คอลัมน์ไม่มีชื่อในไฟล์ใหม่ ยังไม่ใช้เป็น reported total|
|exact_repeat|แถวซ้ำทุกคอลัมน์ต้นทางยกเว้น id หลังแถวแรก|
|repeated_survey_key|วันสำรวจ + ทางแยก + ถนน + เวลา ซ้ำตั้งแต่ 2 แถว อาจเป็นการรายงานซ้ำหรือมีมิติที่ยังขาด ต้องตรวจ|
|repeated_report_key|วันเดือนปีรายงาน + ทางแยก + ถนน + เวลา ซ้ำ ใช้ตรวจ ไม่ตัดอัตโนมัติเพราะอาจสำรวจหลายวันในรายงานเดียว|
|candidate_eligible|ผ่านเกณฑ์ขั้นต่ำของ pipeline ปัจจุบัน ไม่รับรองความถูกต้องต้นทาง|

การแทน 0 เป็นสมมติฐานที่ผู้ใช้กำหนด ไม่ใช่การยืนยันว่าต้นทางตรวจนับได้ศูนย์ทุกช่อง เก็บ log และจำนวนที่ได้รับผลไว้เสมอ ข้อความที่ไม่ใช่จำนวน/ช่องว่าง/- จะถูก flag โดยไม่แก้เงียบ ๆ ไฟล์ล่าสุดไม่มีกรณีเหลือใน numeric_unresolved

การ matching หลักใช้เดือน/ไตรมาสรายงานและ covid_period จากไฟล์ มี audit ทางเลือกของเดือนสำรวจแยกให้ตรวจความไวต่อการเลือกฐานเวลา ไตรมาสรายงานเดียวกันไม่ได้ยืนยันว่าสำรวจฤดูกาลเดียวกัน

| คอลัมน์ EDA | ความหมาย |
|---|---|
|period|ชื่อช่วงเช้า/กลางวัน/เย็นที่มีในไฟล์ใหม่ เก็บไว้; ความเทียบเคียงยังใช้ start/end จาก time_period|
|vehicle_total|ผลบวกจำนวนรถ 6 ประเภทที่ผ่านกติกา clean|
|vehicles_per_hour|vehicle_total / period_hours|

ดัชนีหลัก = median ภายใน location+time+covid_period / median Before ของหน่วยเดียวกัน × 100 แล้วหา median ของดัชนีหน่วย ไม่หารเมื่อฐานเป็น 0
